# AgriSynch v1.0.0 - Quick Start Guide

## 📱 Installation

### Method 1: Direct APK Installation (Easiest)
1. **Download** `app-release.apk` from GitHub releases
2. **Transfer** the APK to your Android phone
3. **Open** Files/File Manager app
4. **Navigate** to the APK file
5. **Tap** to install
6. If prompted, enable "Install from Unknown Sources"
7. **Grant** the requested permissions
8. **Launch** AgriSynch!

### Method 2: Via ADB (Android Debug Bridge)
```bash
# Connect phone via USB
adb install app-release.apk
```

## 🚀 First Time Setup

### 1. Create Your Account
- Launch AgriSynch
- Tap **"Sign Up"**
- Choose role: **Buyer** or **Farmer**
- Enter email and password
- Complete your profile

### 2. For Buyers 🛒
- **Browse** products from farmers
- **Add to Cart** using the shopping cart icon
- **View Cart** to see selected items
- **Checkout** with order confirmation
- **Track Orders** in "My Orders"
- **Rate Farmers** after delivery
- **Message Farmers** with questions
- **Manage Account** in Settings

### 3. For Farmers 👨‍🌾
- **Add Products** with photos and pricing
- **Manage Inventory** and stock levels
- **View Orders** from buyers
- **Message Buyers** for pickup/delivery
- **Track Finances** in Dashboard
- **Create Tasks** to organize farm work
- **View Calendar** for farm planning
- **Update Profile** with farm details

## 🔍 Finding Products

### Browse
1. Tap **Home** or **Products**
2. Scroll through featured products
3. Tap product card for details
4. Read reviews and ratings

### Search
1. Tap search icon
2. Enter product name (e.g., "Rice", "Vegetables")
3. Filter by category if needed
4. Tap to view details

### Categories
- Grains & Cereals
- Vegetables
- Fruits
- Dairy & Poultry
- Organic
- Seasonal Produce

## 📋 Placing an Order (Buyer)

1. **Find Product** you want
2. **Tap** product card
3. **Review Details** (price, farmer, reviews)
4. **Tap "Add to Cart"** 🛒
5. **View Cart** - tap cart icon
6. **Proceed to Checkout**
7. **Review Order Summary**
8. **Confirm Order**
9. **Order Placed!** ✅
10. **Track in "My Orders"**

## ✏️ Adding a Product (Farmer)

1. Tap **Products**
2. Tap **+ Add Product**
3. **Fill Details**:
   - Product name
   - Category
   - Description
   - Price (in your currency)
   - Unit (kg, piece, etc.)
   - Stock quantity
4. **Add Photos** (tap to add images)
5. **Save Product**
6. Product appears on marketplace!

## 🐛 Troubleshooting

### App Won't Install
- **Ensure** Android 13+ 
- **Enable** "Install from Unknown Sources"
- **Clear** cache and try again

### Can't Log In
- **Check** internet connection
- **Verify** email and password
- **Reset** password via "Forgot Password"

### Product Photos Not Loading
- **Check** internet connection
- **Refresh** the page
- **Clear** app cache: Settings → Apps → AgriSynch → Storage → Clear Cache

### No Notifications
- **Enable** notifications in Settings → Permissions
- **Check** system notification settings
- **Restart** app

### Currency Not Updating
- **Go to** Settings → Preferences
- **Select** different currency
- **App** will refresh prices
