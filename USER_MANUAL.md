## 1. Getting Started

### What is AgriSynch?

AgriSynch connects farmers and buyers for agricultural product sales. Features include product listings, order management, messaging, and real-time weather updates.

### Installation

- **Mobile**: Download APK and install
- **Web**: Open in any modern browser

### Creating an Account

1. Tap **"Sign Up"**
2. Choose **Farmer** or **Buyer**
3. Enter name, email, and password
4. Verify your email
5. Start using AgriSynch!

### Login

- Enter email and password
- Tap **"Log in"**

### Forgot Password?

1. Tap **"Forgot Password?"**
2. Enter email
3. Check email for reset link
4. Create new password

## 2. For Farmers

### Products

**Adding a Product:**
1. Tap **"+"** button
2. Enter name, price, quantity, category
3. Upload image (max 5MB)
4. Tap **"Add Product"**

**Editing/Deleting:**
- Tap product card to edit or delete

### Orders

**Order Statuses:**
- 🟡 **Pending** - New order
- 🔵 **Processing** - Being prepared
- 🟢 **Completed** - Delivered
- 🔴 **Cancelled** - Order cancelled

**Managing Orders:**
1. View orders from dashboard
2. Tap order to see details
3. Update status as needed
4. Buyer gets notified automatically

### Finances

**Add Transaction:**
1. Go to **Finances**
2. Tap **"+"**
3. Choose Income or Expense
4. Enter amount and details
5. Save

**View Analytics:**
- Bar chart shows monthly trends
- Pie chart shows expense breakdown
- Recent transactions list
- Total income and expenses

### Weather

- Auto-loads on dashboard
- Shows current temperature and conditions
- Updates every 10 minutes

## 3. For Buyers

### Browsing Products

1. Tap **"Browse Products"**
2. Use **search bar** to find items
3. **Filter by**:
   - Category
   - Location
   - Price range
4. **Sort by**: Newest, price low-to-high, or high-to-low
5. Scroll down to load more products

### Shopping Cart

**Add to Cart:**
- Tap **"Add to Cart"** on any product
- Adjust quantity as needed
- Cart icon shows item count

**Place Order:**
1. Tap **cart icon**
2. Review items
3. Tap **"Place Order"**
4. Confirm details
5. Order sent to farmers

### My Orders

**View Orders:**
- See all orders from dashboard
- Check order status
- View order details

**Order Statuses:**
- 🟡 **Pending** - Waiting for farmer
- 🔵 **Processing** - Being prepared
- 🟢 **Completed** - Delivered
- 🔴 **Cancelled** - Order cancelled

### Reviews

**Leave a Review:**
1. Go to completed order
2. Tap **"Leave Review"**
3. Rate 1-5 stars
4. Write comment (optional)
5. Submit

### Reporting Issues

**Report a Product:**
1. Find the product in **Browse Products**
2. Tap the **flag icon** on the product card
3. Select a category:
   - Inappropriate Content
   - Misleading Information
   - Spam or Scam
   - Counterfeit Product
   - Prohibited Item
   - Other
4. Write a description (10-500 characters)
5. Tap **"Submit Report"**

**Report a User:**
1. Open a chat with the user
2. Tap the **info icon** in the top right
3. Tap **"Report"** button (red flag icon)
4. Select a category:
   - Harassment or Bullying
   - Spam or Scam
   - Impersonation
   - Inappropriate Behavior
   - Fraudulent Activity
   - Other
5. Write a description (10-500 characters)
6. Tap **"Submit Report"**

**What Happens Next:**
- Report sent to admin team
- Reviewed within 24-48 hours
- Appropriate action taken if needed
- You'll be notified of the outcome

**Note:** False reports may result in account suspension.

## 4. For Admins

### Access Admin Portal

**From Settings** (if logged in as admin):
- Open **Settings**
- Tap **"Admin Dashboard"**

**Secret Login Sequence:**
1. Tap **logo** 5 times
2. Then tap **"Log in to continue"** 5 times
3. Enter admin credentials

### User Management

**Ban/Unban Users:**
1. Find user in list
2. Tap **"Ban User"** or **"Unban User"**
3. Confirm action

**Ban Effects:**
- User logged out immediately
- Cannot access account
- Products hidden
- Orders frozen

### Platform Overview

**View Statistics:**
- Total users
- Total products
- Total orders
- Platform revenue

**Manage:**
- All products
- All orders
- User accounts
- Platform analytics

### Reports Management

**Access Reports:**
1. Go to **Admin Dashboard**
2. Tap **"Reports"** tab
3. View all user-submitted reports

**Filter Reports:**
- **All** - View all reports
- **Pending** - New reports awaiting review
- **Reviewed** - Reports being investigated
- **Resolved** - Issues fixed or addressed
- **Dismissed** - Reports found invalid
- **Products** - Only product reports
- **Users** - Only user reports

**Review a Report:**
1. Tap on any report to view details
2. See reporter information, category, and description
3. Choose an action:
   - **Mark Reviewed** - Acknowledge and investigate
   - **Mark Resolved** - Issue fixed/addressed
   - **Dismiss** - Report is invalid or not actionable

**Report Details Include:**
- Type (Product or User)
- Reported item name
- Category of violation
- Reporter name and email
- Description of issue
- Date submitted
- Current status

**Best Practices:**
- Review reports within 24-48 hours
- Investigate thoroughly before taking action
- Document actions taken in admin notes
- Follow up with reporters when appropriate
- Monitor repeat offenders

## 5. Common Features

### Messages

**Start a Conversation:**
- From product page: Tap **"Message Farmer"**
- From Messages: Tap **"+"** and select user

**Send Messages:**
- Type in text field
- Tap send button
- Messages appear instantly

### Notifications

**Types:**
- Order updates
- New messages
- System alerts

**Settings:**
- Go to **Settings → Notifications**
- Toggle on/off for each type

### Settings

**Dark Mode:**
- Toggle in **Settings**
- Reduces eye strain
- Saves battery

**Currency:**
- Choose PHP (₱), USD ($), or EUR (€)
- Updates all prices
- Display only (doesn't change actual prices)

**Account:**
- Change password
- Update profile
- Log out

## 6. Troubleshooting

### Can't Log In
- Check email and password
- Use "Forgot Password" if needed
- Verify your email address
- Check internet connection
- Try clearing cache

### App is Slow
- Check internet connection
- Close other apps
- Restart device
- Clear app cache
- Update to latest version

### Images Won't Load/Upload
- Check internet connection
- Image must be under 5MB
- Use JPG or PNG format only
- Allow camera/gallery permissions
- Try compressing image first

### Orders Not Showing
- Pull down to refresh
- Check internet connection
- Wait a moment for sync
- Contact other party to verify

### Messages Not Working
- Check internet connection
- Ensure not banned
- Restart app
- Check notification settings

### Browser Back Button Not Working (Web)
- Refresh page (Ctrl+Shift+R)
- Clear browser cache
- Update browser
- Try different browser

## FAQ

**Q: Can I have both farmer and buyer accounts?**  
A: No, use separate emails for each account type.

**Q: Are there any fees?**  
A: No platform fees currently.

**Q: How do I delete my account?**  
A: Contact support for account deletion.

**Q: Can I cancel an order?**  
A: Contact the farmer/buyer immediately to discuss cancellation.

**Q: Is payment handled by AgriSynch?**  
A: No, arrange payment directly with farmer/buyer.
